# Changelog — Kairos Influence Website Project

All notable changes to the Kairos Influence website project will be documented in this file.

## [3.0.0] — 2026-11-03 (Part 3 Summative)
### Added
- Created `js/main.js` script providing client-side interactive capabilities.
- Added dynamic, accessible mobile menu toggle supporting `aria-expanded` attributes.
- Implemented client-side form validation and dynamic feedback styling on `enquiry.html`.
- Implemented client-side form validation and success/error reporting on `contact.html`.
- Linked `js/main.js` using the `defer` attribute across all 5 site pages.
- Standardized On-Page SEO metadata, Open Graph attributes, and descriptive image alt tags across all pages.
- Added off-page optimization strategies and social directory link connections.

### Fixed
- Fixed form submission default behavior to prevent page reloads during validation.
- Resolved mobile menu overflow on extra-small screen viewports (<= 480px).
